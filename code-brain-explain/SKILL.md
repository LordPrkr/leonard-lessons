# Code Brain Explain

Use the named plan, or the only active plan, and ask the user to choose when that is ambiguous. Read the plan and the source it touches so each illustration shows inspected current behavior or planned behavior.

Invoke `$show-me` once for the problem and once for the proposed solution, then write both into `explanation.md` beside `plan.md` with any HTML artifacts and link it from the plan.

Done when `explanation.md` has Problem and Proposed solution sections and the plan links to it.
