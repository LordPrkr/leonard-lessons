# Code Brain Writeback

Persist each material finding (one that changes scope, design, or recommendation, or would be costly to rediscover) with its evidence to the caller's artifact before your next investigative step. Revise entries in place as evidence changes, and add a pointer under the caller's reusable-candidate section for findings worth distilling.

Done when every material finding is in the caller's findings section and the artifact matches what you present.
