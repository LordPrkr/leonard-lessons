# Prototype Workflow

## 1. Choose the mode

State the mode and the question in the ticket:

- **Experiment:** answer a factual question through observed behavior.
- **Discussion:** help the user decide how something should look or behave by reacting to a concrete artifact.

Done when the ticket identifies the question and the mode that can resolve it.

## 2. Gather the evidence

- **Experiment:** build and run the smallest disposable prototype that answers the question. Record the command and observed result in the ticket note.
- **Discussion:** create the smallest useful artifact, such as an outline, sketch, or interaction mockup. Show it to the user, revise as needed, and record their feedback and decision in the ticket note.

Done when the ticket records the experiment's observed answer or the discussion's user feedback and decision.

## 3. Clean up

Preserve the evidence supporting the decision in the ticket note or a linked artifact, then remove prototype-only source changes.

Done when the decision evidence remains accessible and prototype-only source changes have been removed.
