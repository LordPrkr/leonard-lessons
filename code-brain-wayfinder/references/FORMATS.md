# Map and Ticket Formats

## `wayfinding/<NNN_TOPIC>/map.md`

```md
# <Destination> Wayfinding

## Destination
<What becomes possible when wayfinding ends.>

## Decisions
- [<Ticket title>](./tickets/001-example.md) — <one-line answer>

## Fog
- <Uncertainty not yet a precise question.>

## Out of Scope
- <Excluded work and why.>

## Outcome
<First slice, chosen next-session skill and why, and later the plan or slice-index link.>
```

## `wayfinding/<NNN_TOPIC>/tickets/<NNN_SLUG>.md`

```md
# <Ticket title>

Issue: <tracker URL or ID> · Type: <Grilling | Research | Prototype | Task>

## Question
<The precise decision this ticket resolves.>

## Blocked By
- <Relative link to each blocking ticket, or None.>

## Resolution
<Answer and consequences, written when resolved.>

## Evidence
- <Cited source, command output, or user decision.>
```
